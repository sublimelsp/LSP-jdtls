Breaking changes:

- LSP-jdtls now uses jdtls 1.63.0, which needs Java 25 or newer to run. Earlier versions of Java fail to start it.
  Install a JDK 25 or newer and point `JAVA_HOME` or the `java.jdt.ls.java.home` setting to it.

  If you can't use Java 25 yet, you can keep using jdtls 1.61.0, the last version that runs on Java 21, by setting
  `"version": "1.61.0"` in the LSP-jdtls settings.

Changes:

- Class files of libraries and the JDK are opened through LSP's support for `workspace/textDocumentContent`, which
  needs LSP 2.14.0 or newer.
- New settings from jdtls: `java.classpath.variables`, `java.codeGeneration.generateCommentsInMarkdown`,
  `java.referencesCodeLens.includeFields`, `java.templates.catchBody`, `java.templates.methodBody`,
  `java.templates.methodBodySuper` and `java.templates.preferPackagePrivateVisibility`. `java.search.scope` can be set to
  `projectOnly` to search only sources, tests and referenced projects.
