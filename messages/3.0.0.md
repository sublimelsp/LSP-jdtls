Breaking changes:

- The key used to override LSP-jdtls settings in project settings has changed from `jdtls` to `LSP-jdtls`.
  If you use project-specific overrides for LSP-jdtls, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "jdtls": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-jdtls": {
                  // ...
              }
          }
      }
  }
  ```
